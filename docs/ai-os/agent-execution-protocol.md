# AI OS Agent Execution Protocol

Default: Understand -> Gather Context -> Choose Tools -> Plan -> Execute -> Verify -> Report.

Multi-step work uses Discovery -> Implementation -> Validation -> Finalization, with verification after critical milestones.

On failure: read the actual error, classify it, retry only when justified, use a safe fallback, and report unresolved failures accurately.

Never claim completion without evidence. Destructive, irreversible, financial, publishing, production, or externally consequential actions require the required authorization.
