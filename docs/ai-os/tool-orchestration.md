# AI OS Tool Orchestration

Choose the direct tool based on the required information or action.

## Routing
- Code/repository: repository, files, shell, Git, tests.
- Project files: private project/file tools; do not replace private sources with public search.
- Web research: current/changing facts, explicit lookup, external verification, official docs.
- Design: Canva/Adobe/image tooling when visual work is required.
- Automation: scheduled/recurring/monitoring work only when requested.
- Integrations: use connected systems when they materially reduce manual work.

## Decision before tool use
1. Required information/action
2. Direct-access tool
3. Reversibility
4. Authorization requirement
5. Verification method

After execution: Action -> Result -> Verify -> Report.
