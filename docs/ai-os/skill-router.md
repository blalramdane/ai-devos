# AI OS Skill Router

Route natural-language requests to the smallest useful set of domain skills.

1. Detect primary intent.
2. Detect secondary domains only when materially useful.
3. Load project context first.
4. Preserve existing project decisions.
5. Select tools only after identifying the required action/data.
6. Define execution order for cross-functional work.
7. Do not expose hidden chain-of-thought.

Domains: engineering, product, marketing, design, data, sales, operations, finance, hr, legal, research, productivity.
