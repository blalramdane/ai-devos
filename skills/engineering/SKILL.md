# Engineering Skill

Trigger: code, repositories, APIs, architecture, debugging, tests, builds, deployment, technical reviews.

Bug workflow: Reproduce -> Evidence -> Root Cause -> Fix -> Test -> Verify.

Feature workflow: Requirement -> Architecture -> Implementation -> Test -> Build -> Verify.

Review: correctness, security, data integrity, performance, maintainability, tests, regressions, deployment impact.

Project behavior: inspect existing implementation before proposing replacement; preserve contracts; prefer minimal reliable changes.
